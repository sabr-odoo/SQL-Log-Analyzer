Query type

Exact model match. Use * as wildcard (sale.order* includes sale.order.line). Separate several models with commas.

How do I capture a log?
  • Odoo: start with --log-level=debug_sql, reproduce the slow action, save the log.
  • PostgreSQL: set log_min_duration_statement = 100 and reload. This adds the duration: … ms values needed for timing checks.
  • Reproduce one slow action only, so the log stays focused.
